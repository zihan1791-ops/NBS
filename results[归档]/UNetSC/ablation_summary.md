## arm 说明

- **baseline**：不使用 ScConv 的 U-Net 基线。
- **encoder_deep**：仅编码器深层 down3 / down4 使用 ScConv。
- **bottleneck**：仅瓶颈 down4 使用 ScConv。
- **decoder_deep**：仅解码器深层 up1 / up2 使用 ScConv。
- **encoder_bottleneck**：编码器深层 down3 / down4 使用 ScConv。
- **all**：所有编码器与解码器 DoubleConv 块使用 ScConv。

## 结果概述

当前 SD900 三种子均值中，基线 test mIoU 最高；各 ScConv 位置消融的均值均略低于基线。瓶颈组最接近基线；全网替换的参数量最低，但 mIoU 均值下降幅度相对较大。该结果仅适用于当前数据划分、训练协议和 ScConv 实现，不能据此推断其他数据集表现。
