# NBS 项目检查与论文落地方案

> 检查日期：2026-10-19  
> 检查范围：`G:\NBS` 项目结构、NEU-Seg 固定划分、当前代码/配置、`../results[归档]/results2中断`、`logs/` 及已有项目报告。  
> 本报告将已观察到的项目事实与建议补做的方案分开。结果数值以当前 `../results[归档]/results2中断` 和各 run 的 `metrics.json` 为准；旧报告中的推断不自动视为已证实结论。

## 1. 执行摘要

项目已经具备可重复运行的 U-Net、BiSeNetV2、BiSeNetV2+ScConv 训练和评估框架，NEU-Seg 的训练、验证、测试划分清单固定，测试集也没有参与逐轮 checkpoint 选择。ScConv 方面已有 22 个完成的 90 轮实验，覆盖基线、附加式位置/残差/门控消融和替换式压缩。

目前最清楚、可以报告的发现是：在当前 90 轮训练协议和 NEU-Seg 划分上，D2（BGA 后直接加入无残差 ScConv）三种子 test mIoU 均高于 B0；均值分别为 **0.8699** 和 **0.8649**，均值差约 **+0.0050（+0.50 个百分点）**。这说明“D2 配置在这批实验中表现更好”，但还不足以断言提升是 ScConv 算子本身造成的：C2a/C2b/C2c 归因对照尚无完成结果；200 轮主结果配置也尚无完成记录。

论文建议先定位为一项**严格控制条件下的 ScConv 应用与消融研究**，而不是先宣称普适的“容量定律”或把 D2 增益写成 ScConv 的确定贡献。接下来优先补齐匹配的归因对照和长轮次主表；再决定是否扩展到第二数据集。旧结果里已经出现的趋势很有价值，但跨协议结果、单种子结果和重复使用 test 集的影响必须透明交代。

## 2. 项目现状盘点

### 2.1 代码与实验资产

- `train.py` 是统一入口，以 `--model` 选择 `unet`、`bisenet` 或 `scconv`，以 `--config` 选择配置。
- `models/` 包含 U-Net、BiSeNetV2 及 ScConv 变体；ScConv 实现提供 fused/detail/semantic 插入、卷积替换及 fused 位置的普通块对照。
- `scripts/` 包含数据读取、指标计算、作图、训练脚本、结果汇总、成本测量和 ScConv 诊断工具。
- `config/` 已有 90 轮消融配置、C2a/C2b/C2c 对照配置、P200 长轮次配置及 U-Net P200 配置。
- `run_ablation.ps1` 支持断点跳过、逐实验日志和 C2a/C2b/C2c 队列；`run_experiment.py` 可按配置和种子串行启动并刷新汇总。
- 已完成 run 有 `config.json`、`best.pth`、`metrics.json`、`history.jsonl`、`result.txt`、训练总览图、PR/ROC/F1 曲线、混淆矩阵和分割样例图等产物，便于追溯。

### 2.2 数据与划分

`data/NEU_Seg-main/splits/` 中清单数量为：

| 子集 | 数量 | 用途 |
| --- | ---: | --- |
| Train | 2,904 | 训练与训练增强 |
| Val | 726 | 每轮验证、选最佳 checkpoint、调度/早停依据 |
| Official test | 840 | 训练结束后评估 |

`split_summary.json` 记录原训练池 3,630 张以 seed 42 做确定性 80/20 划分，官方 test 840 张保留。输入尺寸为 200×200，四类为背景、夹杂、斑块、划痕。配置默认训练增强包括水平/垂直翻转和 90°倍数旋转。

这是合理的训练/验证/测试设计。正式论文前仍应核查清单中的文件均能找到对应图像和掩膜、标签映射正确、训练/验证 ID 没有交叉，并对跨源子集做文件哈希/近重复图检查。样本名在 train/test 两个源目录中重复并不自动代表泄漏，需按实际文件内容判断。

### 2.3 已完成实验规模

当前自动汇总涵盖 22 个完成 run、10 个实验臂：B0、S0、D1、D2、P1、P2、G1、R1、R2、R1D2。主批次均为 90 轮、cosine 调度、5 轮 warmup、batch 32、初始学习率 0.001、weight decay 0.0001，并开启确定性算法。B0、S0、D2、R1、R2、R1D2 各有 3 个种子；D1、P1、P2、G1 各只有 1 个种子。

**当前 `../results[归档]/results2中断` 中没有** C2a/C2b/C2c、P200 B0/D2 或 U-Net P200 的完成结果。虽然对应配置已写好，队列脚本也有 C2 入口，但配置存在不等于实验已经完成。旧 `../results[归档]` 下的 300/350 轮结果来自不同训练协议，只宜作为历史参考，不能与当前 90 轮主批次直接合并计算均值或差值。旧 U-Net 目录也不是一套完整的匹配主结果。

## 3. 当前结果怎么解释

### 3.1 90 轮批次汇总

下表是 test mIoU（四类宏平均，包含背景）均值±样本标准差；n=1 时没有方差估计。

| 实验臂 | 含义 | 种子数 | test mIoU | 与 B0 的均值差 |
| --- | --- | ---: | ---: | ---: |
| B0 | 原版 BiSeNetV2 基线 | 3 | 0.8649 ± 0.0012 | — |
| S0 | fused 后 ScConv，带残差、初始 scale=0.1 | 3 | 0.8631 ± 0.0043 | −0.0018 |
| D1 | fused 后 ScConv，带残差、初始 scale=1.0 | 1 | 0.8633 | −0.0016 |
| D2 | fused 后直接 ScConv，无残差 | 3 | **0.8699 ± 0.0003** | **+0.0050** |
| P1 | detail 分支后 ScConv | 1 | 0.8632 | −0.0017 |
| P2 | semantic 分支后 ScConv | 1 | 0.8645 | −0.0004 |
| G1 | 改变 SRU gamma 归一化 | 1 | 0.8642 | −0.0007 |
| R1 | detail 分支部分卷积替换为 ScConv | 3 | 0.7940 ± 0.0119 | −0.0709 |
| R2 | semantic 分支 GELayerS1.conv1 替换为 ScConv | 3 | 0.8576 ± 0.0040 | −0.0073 |
| R1D2 | R1 替换 + D2 | 3 | 0.7877 ± 0.0641 | −0.0772 |

D2 与 B0 使用了相同的三个种子，逐种子的差值约为 +0.0059、+0.0052、+0.0040，方向一致。这比只比较两组均值更有信息；正式分析应以**配对种子差值**为主，同时给出原始每种子结果和区间，不把“标准差不重叠”写成显著性检验。

### 3.2 可支持与暂不能支持的说法

**现有证据支持：**

- 在这套固定数据划分、当前实现及 90 轮训练协议下，D2 的三种子 test mIoU 高于 B0；提升同时出现在主要前景类别的 IoU 上。应同时报告每种子数值、宏平均和前景类别表现。
- S0 三种子均值与 B0 接近且波动更大；D1/P1/P2/G1 的单种子只能作为筛选结果，不能写成“已证明无效”。
- R1 明显低于基线，R2 有较小下降；参数/FLOPs 汇总显示 R1、R2 会减少参数，但精度代价不同。这些结果说明替换位置值得研究，不等于已经建立因果机制。
- 当前 B0 参数量约 3,622,820，D2 约 3,652,900；D2 参数增加约 0.83%，FLOPs 从约 3.76 增到 3.80 GFLOPs（当前计数口径）。因此 D2 是轻微增参方案，不能称为压缩/轻量化收益。

**目前不能下定论：**

- “D2 的 +0.50% 是 ScConv 本身带来的。”C2 对照实验尚未完成，额外卷积/非线性块也可能解释结果。
- “D2 在充分训练后仍提升 0.50%。”90 轮结果不能代替 200 轮匹配比较；历史 300 轮实验协议不一致。
- “ScConv 在轻量网络上普遍无效”或“容量份额决定精度损失”。当前主要是一种架构、一个数据集；替换实验点数少，尚不能支撑普适规律。
- 将单种子结果描述为稳定趋势；将 n=3 描述为强统计显著性；把像素数量当成独立统计样本。分割像素高度相关，统计重采样应以图像为单位。

### 3.3 需要特别注意的 test 集使用边界

训练脚本在训练过程中用 Val 选 checkpoint，`metrics.json` 也明确记录官方 test 未用于 checkpoint 选择，这一点是正确的。另一方面，项目已经在同一批 840 张 test 上对多个 arm 做了比较，并据此迭代了配置。今后继续反复按 test mIoU 选架构/超参数，会使 test 逐渐成为开发集，最终 test 结果可能乐观偏倚。

建议从现在起冻结 test：C2、200 轮、seed 数和候选模型均通过预先写下的方案确定；训练中只看 Val。论文将现有 test 结果称为“探索性比较”，最后一次主结果评估集中执行并保留全部候选。若要较强地声称可泛化，优先加一个独立数据集/外部测试集作为确认；NEU test 已多次用于方案比较的事实应在项目记录中留档，不能通过重命名消除。

## 4. 推荐论文定位与研究问题

### 推荐定位

目前最稳妥的定位是：**ScConv 在 BiSeNetV2 钢材表面缺陷分割中的应用方式、放置位置和替换代价的受控实证研究**。贡献点不是“换一个模块就涨点”，而是用匹配协议比较附加、残差、位置和替换方式，并在归因对照完成后回答 D2 增益来自哪里。

现有“容量份额定律”“特征冗余压缩算子必然失败”“原创放置准则”等表述强于现有数据。可以把它们作为待检验假设，等剂量实验和外部数据复核完成后再考虑升级为论文主张。

### 研究问题

1. ScConv 放在 BiSeNetV2 的不同位置、以附加式或替换式使用时，对分割精度和模型成本有什么影响？
2. D2 的观察到的增益是否超过同位置普通卷积块或单纯非线性带来的增益？
3. 90 轮下的差异在统一长轮次协议中是否保留？
4. 若替换会掉点，掉点是否随被替换层/分支容量占比变化？这个趋势能否在第二数据集复现？

## 5. 后续实验：按优先级执行

### 阶段 0：锁定协议与数据审计（先做）

1. 固定论文主结果协议：NEU-Seg 200×200、Train/Val/Test=2904/726/840、同一增强、batch 32、AdamW、初始 LR 1e-3、weight decay 1e-4、cosine + 5 warmup、确定性算法、同一 loss 与辅助头权重。
2. 把实验配置、代码版本、数据 split 清单和环境依赖保存进每个 run；检查每个 run 的 `config.json` 完整记录 seed、scheduler、epochs、dataset 和 validation source。
3. 对文件配对、标签取值、清单交叉和重复图做一次只读核查；记录数据集来源与许可/引用信息。
4. 预先写定最终候选、种子和比较指标，不再依据官方 test 逐个淘汰配置。

### 阶段 1：D2 归因对照（最高优先）

使用现有 C2 配置，在 BGA 后同一位置、无残差、同一训练协议下比较：

| 臂 | fused 后模块 | 目的 |
| --- | --- | --- |
| D2 | ScConv | 候选方法 |
| C2a | Conv1×1 + BN + ReLU | 判断普通轻量卷积是否能解释提升 |
| C2b | Conv3×3 + BN + ReLU | 判断较强普通卷积块的效果/成本 |
| C2c | ReLU | 判断额外激活本身是否有影响 |

建议 D2、C2a、C2b、C2c 使用相同种子（42、123、2024）和相同 90 轮协议；若算力有限，C2c 可先跑一个筛选种子，但不可据此做确定性结论。主分析做配对差值，并报告参数量、GFLOPs、推理延迟。先检查配置的实际 `SC_CONV_RESIDUAL=False` 和唯一差异确实是 fused block 类型。`run_ablation.ps1` 已提供 C2 入口，可分别运行并保留 `logs/`。

**解释规则：**若 D2 与 C2a/C2b 相近，结论是“融合后额外块有帮助”，不能归功于 ScConv；若 D2 在匹配种子下稳定领先且成本有优势，才支持 ScConv 特有收益；若普通卷积精度更高，应报告精度-成本折衷。

### 阶段 2：长轮次主结果表

现有配置已准备 `configScConvB0P200`、`configScConvD2P200`、`configUnetP200`，但还没有完成结果。建议先跑 seed 42 pilot 检查收敛，再**统一**确定所有主模型轮数；不要只给某个模型单独延长训练。

主表候选：

- U-Net（P200 recipe）
- 原版 BiSeNetV2/B0（`configScConvB0P200`，禁用 ScConv）
- BiSeNetV2+D2（`configScConvD2P200`）

pilot 后如统一延长至 300 轮，则三个模型都按相同 300 轮预算、相同 scheduler 逻辑重跑。最终建议每个模型至少 3 个匹配种子；资源允许时增加到 5 个。历史 90 轮消融和 P200/300 轮主结果分表呈现，不混合均值。

U-Net 与 BiSeNetV2 是不同容量/结构的基线，统一训练协议只能改善公平性，不代表参数量或计算量相等。当前 BiSeNetV2 配置还启用辅助分割头（辅助损失权重 0.4），而 U-Net 路径没有对应辅助头；主结果前需决定保留并将深监督作为 BiSeNetV2 原生配置明确报告，或关闭辅助头做一组更纯粹的结构对照，不能把两者描述为损失路径完全相同。报告参数量、GFLOPs、推理速度/显存，并明确计量环境。

### 阶段 3：统计与误差分析

- 每个候选公布各 seed 结果、均值±标准差、配对种子差值；若有足够 seed，再报告配对 bootstrap/置信区间。
- Bootstrap 以测试图像为抽样单位，不能将数千万像素当成独立样本。n=3 只适合初步稳定性比较，不宜过度解读 p 值。
- 同时报四类 IoU/Dice、前景类别宏平均、像素准确率、混淆矩阵；说明 mIoU 是否包含背景（当前汇总口径包含背景）。
- PR/ROC 是像素级 one-vs-rest 曲线；说明阈值/概率累计方式和曲线指标，避免把像素级 AP 误读为图像级检出率。
- 对夹杂、划痕等易混类别做按图像的失败样例分析；至少选典型成功、边界误差和类别混淆案例，不只挑最好看的预测。

### 阶段 4：验证机制与泛化（论文定位需要时做）

1. **替换剂量实验**：R1 的严重下降与 R2 的较小下降目前只是两个不同位置/结构的观测，不能直接推出容量份额因果关系。设计同一分支、同一类型层、逐步增加替换数量的剂量曲线，测每步分支参数变化和精度变化。
2. **第二数据集**：项目数据加载支持 Magnetic-Tile 与 SD-Saliency，但当前 `data/` 中仅见 NEU-Seg。选数据前先核实掩膜语义、类别映射、数据许可及训练/测试划分；不要把另一数据集的异质指标硬合并到 NEU 主表。至少比较 B0、D2 与阶段 1 胜出的普通块对照。
3. **成本测量**：现有成本脚本能测参数与 FLOPs；补固定硬件、batch=1/指定 batch、预热次数、重复次数、同步 CUDA 的延迟和峰值显存。报告均值/中位数与硬件软件环境，不用训练墙钟时间代替推理速度。
4. 可选的 SE/ECA/CBAM 对照只有在研究问题确实要比较模块家族时再做；需相同位置、近似相同训练预算，并在计划里预先列出，避免不断扩展对照造成选择性报告。

## 6. 论文写作方案

### 标题方向（暂定，待归因结果后确定）

- 中文：**ScConv 在轻量化钢材表面缺陷分割网络中的应用方式与性能影响研究**
- 英文：**An Empirical Study of ScConv Integration in Lightweight Steel Surface Defect Segmentation**

标题暂不写“普适准则”“容量定律”或“显著提升”；等 C2、长轮次和外部验证完成，再依据结果收紧或调整标题。

### 章节安排

1. **摘要**：工程问题、研究问题、数据集与划分、模型/实验设计、关键结果（配对多种子）、结论边界。只使用最终冻结评估的主结果。
2. **引言**：钢材表面缺陷像素级分割的应用背景；轻量网络与特征重构模块的动机；当前模块移植研究的可比性问题；明确研究问题和贡献。
3. **相关工作**：NEU-SEG/钢材缺陷分割、BiSeNetV2 与轻量分割、ScConv 原始方法与后续应用。通过正式文献检索核实每条结论，区分原始论文与应用论文；不要把“搜索不到”写成“无人研究”。
4. **方法**：BiSeNetV2 双分支与 BGA 简述；ScConv 的 SRU/CRU；清晰定义附加式、残差式、无残差式、替换式及 C2 对照。给结构图并标注插入位置、通道/尺度。
5. **实验设置**：数据来源、标签映射、固定划分、输入预处理、增强、损失、优化器、调度、batch、epoch、种子、设备、软件版本、checkpoint 选择和测试集隔离；列指标公式与计算口径。
6. **结果**：主模型多种子比较；ScConv 位置/残差/门控消融；D2 归因控制；替换/参数与 FLOPs；类别误差、PR/ROC/F1 和可视化。
7. **讨论**：哪些实验结论能回答研究问题、收益是否特属于 ScConv、精度与成本的折衷、不同类别/边界的影响、与已有文献的差别。
8. **局限性**：单一 NEU 数据集、样本量和标注来源、当前已查看过 test 的开发过程、随机种子数量、分辨率与硬件依赖；根据补实验情况更新。
9. **结论**：只总结被实验直接支持的发现，不外推到所有缺陷数据、所有轻量网络或所有 ScConv 用法。

## 9. 最终建议

先暂停继续扩展 ScConv 位置/超参数搜索，先做 **C2 归因对照 + U-Net/B0/D2 长轮次匹配主表 + 测试集冻结**。完成后根据结果选论文主线：

- 若 D2 稳定优于普通块且有合理计算成本：主线写 ScConv 的受控应用收益。
- 若普通卷积也能达到 D2：主线写融合后细化块的作用，ScConv 不作为独特贡献。
- 若长轮次差异消失：改写为收敛速度/成本问题，或将 D2 作为非稳定的观察，不宣称最终精度提升。
- 若跨数据集不能复现：把结论限定在 NEU-Seg 和当前网络/分辨率，明确外部效度限制。

这样能让论文的结论随证据走，既保留现有消融工作的价值，也避免把项目当前尚未验证的推断写成结果。
