## 一、项目概览

**G:\NBS** 是一个 **钢材表面缺陷语义分割** 实验项目，在 NEU-Seg 数据集上对比三种架构：

表格

| 维度         | 内容                                                         |         |                               |
| ------------ | ------------------------------------------------------------ | ------- | ----------------------------- |
| **数据集**   | NEU-Seg（东北大学钢材表面缺陷），4 类：背景、夹杂 (Inclusion)、斑块 (Patch)、划痕 (Scratch) |         |                               |
| **固定划分** | 训练 2904 / 验证 726 / 测试 840（测试集仅训练结束后评估，无信息泄漏） |         |                               |
| **模型**     | U-Net、BiSeNetV2、BiSeNetV2 + ScConv（空间 / 通道重构卷积）  |         |                               |
| **输入**     | 200×200 RGB，含水平 / 垂直翻转、90°/180°/270° 旋转增强       |         |                               |
| **损失**     | CrossEntropy + Dice 联合损失，BiSeNet 含辅助头（权重 0.4）   |         |                               |
| **优化器**   | AdamW，ReduceLROnPlateau（factor=0.5, patience=6），EarlyStopping（patience=30） |         |                               |
| **入口**     | `train.py --model {unet                                      | bisenet | scconv} --config {config 名}` |

**ScConv 集成方式**：在 BiSeNetV2 的 BGA（双边引导聚合）之前，对融合特征 (fused) 插入 SRU（空间重构单元）+ CRU（通道重构单元），带残差连接（初始 scale=0.1），参数量从 3.62M 增至 3.65M（+0.8%）。

## 四、关键发现与问题诊断

### 1. ScConv 未带来显著性能提升

BiSeNetV2 默认 test mIoU = **0.8753**，BiSeNetV2+ScConv 默认 = **0.8750**，差距仅 0.03%，在参数量增加 0.8% 的情况下几乎可忽略。所有 ScConv 变体中，没有任何一组超过 BiSeNetV2 默认配置。ScConv 的空间 / 通道重构在钢材缺陷这种纹理相对简单的场景下增益有限。

### 2. 降低学习率反而损害性能

ScConv config2（LR=5e-4）和 config3（LR=3e-4）的 test mIoU 分别为 0.8686 和 0.8597，均低于默认 LR=1e-3 的 0.8750。config3 还增加了 weight_decay=3e-4 和 dropout=0.15，过强的正则化导致欠拟合（val loss=0.457 显著高于其他组的 0.41）。

### 3. 可复现性异常（重要）

`bisenetv2_scconv`（默认）与 `bisenetv2_scconv_config1` 的**配置参数完全相同**（LR=1e-3, batch=32, residual_scale=0.1, seed=42），但 val mIoU 分别为 0.8732 和 0.8629，相差 **1.03%**。两者 best_epoch 都是 229、都在 259 轮 early stop，但收敛轨迹不同。这表明：

- 尽管设置了 `CUDNN_DETERMINISTIC=True` 和固定 seed，数据增强（随机翻转 / 旋转）或 DataLoader 多进程仍引入了随机性；
- 1% 的波动幅度大于 ScConv 本身的 "提升"，说明当前实验结论的统计显著性不足，建议每组重复 3 次取均值。

### 4. U-Net 训练被中断

U-Net 仅训练到第 69 轮即停止（history.jsonl 末行为 epoch 69），未达到 EarlyStopping 条件（best=69，patience=30，应训练至 99 轮），且**未执行测试集评估**（无 metrics.json、PR/ROC 曲线、混淆矩阵）。当前 val mIoU=0.8426 仍在上升趋势中（第 65-69 轮连续创新高），提前中断导致 U-Net 结果不完整，无法与 BiSeNet 公平对比。

### 5. 训练效率

- BiSeNetV2 默认训练 253 轮耗时 2h39m，是所有实验中最长的；
- config1（LR=7e-4）因 best_epoch=170 较早收敛，仅 1h07m，但性能也最低；
- ScConv 各组稳定在 1h36m-1h41m，259 轮全部 early stop。

------

## 五、建议

1. **补完 U-Net 训练**：从 best.pth 恢复训练至 300 轮或 early stop，并执行测试集评估，否则三组模型对比不完整。
2. **增加重复实验**：ScConv 的增益（0.03%）小于单次运行波动（1%），建议关键对比组各跑 3 次取均值 ± 标准差。
3. **ScConv  placement 消融**：当前 ScConv 仅作用于 fused 特征，可尝试在 detail branch 或 semantic branch 单独插入，或调整残差初始 scale（0.1→0.5），观察是否有更优配置。
4. **针对 "夹杂" 类优化**：该类 IoU 仅 0.79，是性能瓶颈。可尝试类别加权损失（提高夹杂类权重）、针对小目标的多尺度特征融合，或增加该类样本的增强强度。
5. **config3 正则过强**：LR=3e-4 + WD=3e-4 + dropout=0.15 组合导致欠拟合，建议回退 WD 至 1e-4。
