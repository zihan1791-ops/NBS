# 一、总体策略：2 主线 + 2 支线，用"零代码"结果给主线排序

| 角色                      | 内容                                                         | 为什么这么排                                                 |

# 三、Phase 1：后置诊断（几十分钟，决定 D/P 优先级）

1. **读出训练后的 `ResidualScConv.scale`**（现有 4 个 `best.pth`）、SRU GroupNorm 的 γ 分布，统计"被判为 informative 的通道比例"。
2. **冗余度量**：val 子集上抽 BGA 输出，算通道相关矩阵、SVD 谱、**effective rank（有效秩）**，baseline vs scconv。
3. **Gate 1 判据**：
 - 若 `scale ≈ 0.1` 且 informative 比例 > 90% → **模块是惰性的**，D/P 优先，主线 R/X 需要在"直插/替换"前提下重做；
 - 若 `scale ≥ 0.5`、informative ∈ [0.4, 0.8] → 模块确实在参与，那 0 增益就是"冗余与精度无关"，精力全押 R + L。

# 八、风险与对策

| 风险                                                         | 对策                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 确定性与 `interpolate`/`avg_pool` 反向冲突，开全确定性后报错 | `warn_only=True` 先放行并记录；只对违反项用 `upsample_nearest`/固定尺寸规避 |

| 替换式（R1）掉点                                             | 这正是论文关心的问题，如实报"等 FLOPs 下持平/略降"也是有效结论 |
| 跨流（X1）实现偏离 BGA 太多导致对比不公平                    | 保留"BGA 原样 + 前置 ScConv"的对照（即 P3 detail+semantic），确保变量唯一 |
